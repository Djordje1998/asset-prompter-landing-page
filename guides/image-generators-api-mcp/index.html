Which image and video generators have an API or an MCP server

A coding agent can only press Generate where a generator gives it a way in: an API or an MCP server. Here is which ones do, what it costs, and the source for each, checked on 8 October 2026.

By Đorđe Novaković, who makes Asset Prompter · Updated 8 October 2026

The short answer

Midjourney and Google Flow have no public API. Midjourney's rules forbid automating it; Flow's models, Veo and Nano Banana, are in Google's Gemini API, billed apart from a Google AI plan.

ChatGPT Images, Grok Imagine, Leonardo.Ai and Luma have APIs, billed apart from the app's plan where the vendor says how; Leonardo and Luma also have MCP servers, which run on that API billing.

Higgsfield, Ideogram, Krea, Kling and Runway have official MCP servers you sign in to with your account; Ideogram and Runway say MCP use draws on the same plan or credits as their app.

What this means for your coding agent

The generator has an official MCP server on your plan

Higgsfield, Ideogram and Runway, and Krea when you sign in: the agent can generate by itself. Kling's server signs in with your account too; whose credits it uses, the app's or the API's, is not stated. Asset Prompter is optional there. As the home page's answer puts it, it still helps if you want to choose and approve every result yourself and keep each version in the folder, or if you use features the tool keeps to its own app.

It has an API, billed apart from your plan

ChatGPT Images, the Gemini API (Veo, Nano Banana), Grok Imagine, Leonardo.Ai and Luma: the agent can generate through a script or an MCP server with an API key, and you pay per generation on top of any plan you already have.

It has no API

Midjourney and Google Flow: the agent can't press Generate. Automating the web app breaks Midjourney's terms. What is left is to carry prompts and files by hand, or through a shared folder like Asset Prompter's; the five ways to get images into your agent's project compares them, and how this site's pictures were made shows the folder with Flow.
