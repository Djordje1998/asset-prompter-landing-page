Without it, you are the courier

Your agent knows which pictures it needs, but they come from a generator you use by hand. So the carrying falls to you.

  • You copy a prompt out of the chat, paste it into the generator, download the result, rename it and move it into the repo.
  • The agent never sees what came out, so you describe the picture back to it in words.
  • Three rounds later nobody knows which file was the good one, or which prompt made it.

What the folder gives your agent

Everything you generate lands where the agent can look.

It sees every version

A new version never replaces an old one. Every result, your change request and its own review stay in the slot folder, where it can read them.

It makes variants of the final picture

Crops, other sizes, other formats and small edits, made from the file you approved. No new generation.

They stay in one place beside the final picture. In the app you open them from its tile and copy any of them with one click.

It checks a clip it can't play

An agent can't watch video. So the app turns every clip you drop into pictures and numbers it can read.

What it is good for

  • Images for a site your agent is building

    Hero banners, section photos, backgrounds. The agent knows where each one goes and what it has to do there, and writes that into the slot.

  • One product across many assets

    Approve a master image first, and later slots take it as their reference. A slot that depends on another waits until that one is approved.

  • Short clips from approved stills

    A video slot can take an approved image as its start frame. The agent then checks the motion second by second, and whether the clip loops.

  • App and brand art

    Icons, empty states, illustrations. Once you approve one, the agent exports the sizes and formats it needs from that file.

    Films, ads and short scenes

    1. Script. The agent writes it and splits it into shots, in the project folder, where you can read it.
    2. Cast and props. One slot for each character, prop and place. You approve them once, and every shot takes them as references, so the same face and the same bag turn up in every frame.
    3. Shots. A still for each shot, then a clip that starts from it. The slots are numbered in shot order, so you always know what to generate next.

It doesn't generate anything

You press Generate in your own tool, every time. For batches that run while you are away, pick a generator with an API or an MCP server.

A good fit if

  • Your generator has no API, and you want your agent to see the results.
  • You already pay for a generator plan and want no API bills on top.
  • You want the last word. Nothing is done until you approve it.
  • You want it on your machine: plain files in a folder, no account.

Know before you install

  • Presets ship for the seven generators above. Another tool needs a short preset file.
  • Your agent has to work with files. A chat window in a browser can't.
  • The agent can't hear. Checking a clip's sound is your job.
  • Setup covers Windows and Linux. On macOS you install Bun yourself.

You do it

Two steps by hand

  1. Download the folder

    Get the ZIP and unzip it anywhere, or clone the repository.

    Download ZIP
  2. Run setup once

    On Windows, double-click setup.bat. On Linux, run sh setup.sh in the folder. Setup installs Bun, ffmpeg and the app's packages, adds an Asset Prompter icon and opens the app.

Then, in the app: open a project, press Copy agent instructions and paste it into a chat with your agent. A two-minute tutorial opens on the first start.

Before you try it

Which agents does it work with?

Any agent that can read and write files in the project folder and follow a written guide. The app writes that guide, HOW-TO-USE.md, into every project. If the agent can also run a command in the background and is woken when it ends, Notify agent wakes it. If not, you tell it "done" in the chat.

Which generators?

Any tool you can paste a prompt into and get a file out of. A preset tells the agent which models, modes, aspect ratios and lengths a tool offers, and the app warns you when a result doesn't match. Presets for ChatGPT Images, Dreamina, Google Flow, Grok Imagine, Leonardo.Ai, Luma and Midjourney are included, and a slot can use any of them, so one project can mix tools. Each preset is a short text file you can copy and edit for another tool.

My generator has an MCP server. Do I still need this?

Maybe not. Several generators now offer an official MCP server that lets an agent generate on your plan, among them Higgsfield, Ideogram, Krea and Runway. Asset Prompter still helps there if you want to choose and approve every result yourself and keep each version in the folder, or if you use features the tool keeps to its own app.

Do I need an agent at all?

No. New slot lets you write prompts yourself. You still get versions, results side by side and a shelf of approved files.

Does anything leave my machine?

The app listens on 127.0.0.1 only, has no account, and keeps everything in your project folder. Two things do go out: the interface loads its fonts from Google Fonts, and whatever you paste into your generator goes to that generator.

What does it cost?

Nothing. You pay for your generator and your agent, as you do now.

Can I change an asset after I approved it?

Yes. Remove the approval in Details to reopen the slot, or clone the slot to try another direction and keep the original.
